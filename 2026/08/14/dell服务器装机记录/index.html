    Dell PowerEdge R760xs 服务器装机记录

    服务器型号：Dell PowerEdge R760xs
    Service Tag：89G0494
    RAID控制器：PERC H755 Front
    操作系统：Windows Server 2019 x64

    一、问题背景

    装机初期使用U盘启动进入PE系统，通过GHOST方式还原Windows Server 2019镜像，但出现一系列问题：

    1. 磁盘管理中找不到物理硬盘，只能看到U盘自身分区
    2. 装完系统后开机提示 “No boot device available”（找不到启动设备）
    3. 修复引导后开机变为蓝屏（INACCESSIBLE_BOOT_DEVICE）

    二、排查与解决过程

    1. RAID 配置（Lifecycle Controller）

    服务器出厂硬盘未做RAID，需要先创建虚拟磁盘：

    • 开机进入 Boot Manager → Launch Lifecycle Controller
    • 进入 硬件配置 → 配置向导 → RAID配置
    • 选择控制器：PERC H755 Front in SL 5
    • RAID类型：Windows RAID
    • 选中2块物理盘（Physical Disk 0:1:0 / 0:1:1，各3725.5GB）
    • RAID级别：RAID 0（追求容量，无容错，如重要数据建议改用RAID 1）
    • 完成后生成虚拟磁盘，容量约 7451GB，重启使配置生效

    2. 分区表与EFI引导问题

    首次GHOST恢复系统后开机提示找不到启动设备，排查发现磁盘上没有正确的EFI系统分区（ESP），导致UEFI无法识别为可启动盘。

    解决方法：使用PE自带的 DiskGenius 分区工具重建标准UEFI分区结构：

    1. 打开DiskGenius，选中目标磁盘（HD0: DELLPERCH755Front 7451GB）
    2. 删除现有全部分区
    3. 使用 “快速分区(F6)” 功能：
      • 分区表类型：GUID (GPT)
      • 分区数目：自定1个
      • 勾选 **”创建新ESP分区”**（300MB）
      • 勾选 **”创建MSR分区”**（16MB）
      • 勾选 “重建主引导记录(MBR)”
    4. 确定执行，生成标准分区结构：
      • ESP(0) - FAT32 - 300MB
      • MSR(1) - 16MB
      • 系统(C:) - NTFS - 约7451GB

    3. RAID驱动缺失导致蓝屏

    重新分区并恢复系统后，能进入引导流程但出现 蓝屏（INACCESSIBLE_BOOT_DEVICE），原因是系统未安装 PERC H755 RAID控制器驱动，Windows无法识别硬盘控制器。

    解决方法：

    1. 从Dell官网下载驱动：

      • 搜索产品：PowerEdge R760xs 或 PERC控制器
      • 驱动名称：适用于PERC控制器的Windows Server 2019驱动程序
      • 文件名：SAS-RAID_Driver_J21CF_WN64_7.730.02.00_A10.EXE
      • 版本：7.730.02.00，厂商 Broadcom Inc

    2. 解压该EXE安装包，找到驱动文件所在目录（路径示例：\payload\），核心文件：

      • megasas35.inf
      • megasas35.sys
      • megasas35.cat

    3. 将驱动文件夹拷贝至U盘，带回服务器PE环境

    4. 在PE中通过命令行将驱动注入系统盘（注意确认系统盘实际盘符，PE环境中盘符可能与预期不同）：

      dism /image:D:\ /add-driver /driver:U:\H755\payload /recurse

      （本次实际系统盘为 D 盘，通过 dir 盘符:\Windows 逐个测试确认）

    5. 提示”操作成功完成”后，拔出U盘重启

    4. 启动验证

    重启后进入 F11 Boot Menu，可见启动项：

    RAID Controller in SL 5: EFI Fixed Disk Boot Device 1

    选择该项启动，系统成功进入Windows Server 2019，磁盘管理显示：

    • 系统(C:) — NTFS — Healthy (Boot, Page File, Crash Dump, Primary Partition)
    • EFI System Partition — Healthy

    装机成功。

    三、后续操作

    分区规划

    系统盘C当前占满全部7450GB空间，建议通过磁盘管理”压缩卷（Shrink Volume）”划出数据盘：

    • 系统盘（C:）建议保留 200GB以上，避免后续更新、软件安装空间不足
    • 计算方式：压缩量(MB) = 可压缩总空间 - 保留给C盘的空间(MB)
    • 压缩完成后，剩余”未分配”空间可新建分区作为数据盘（如D盘）

    远程桌面配置

    若需远程管理该服务器，简单方式（单用户管理）：

    1. 打开”服务器管理器” → “本地服务器” → 找到”远程桌面”
    2. 点击”已禁用”链接 → 勾选”允许远程连接到此计算机” → 确定

    注意：若之前操作过”添加角色和功能”向导并勾选了 Remote Access / Remote Desktop Services（面向多用户/企业级场景），可能导致该设置暂时置灰，建议：

    • 取消该向导（若未点击”安装”确认）
    • 重启服务器后再检查远程桌面设置状态
    • 若仍异常，检查本地组策略（gpedit.msc → 计算机配置 → 管理模板 → Windows组件 → 远程桌面服务）

    四、经验总结

    1. 服务器装机前务必先做RAID配置，否则装机时看不到硬盘
    2. GHOST/PE方式装机需确保GPT分区表 + 正确的EFI系统分区，否则UEFI无法识别为可启动盘
    3. 企业级RAID卡（如PERC系列）驱动不在系统默认驱动库中，必须从Dell官网下载对应驱动，通过 dism /add-driver 注入系统或在安装Windows时手动加载，否则会出现蓝屏 INACCESSIBLE_BOOT_DEVICE
    4. PE环境下盘符分配可能与预期不同，操作前建议用 dir 盘符:\Windows 逐一确认目标系统盘的实际盘符
    5. 驱动下载建议优先选择与操作系统版本严格匹配的驱动（如Windows Server 2019专用驱动），如无匹配版本可尝试相邻版本（如Server 2022）驱动，一般向下兼容
